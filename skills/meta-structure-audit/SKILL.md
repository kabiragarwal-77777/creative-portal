# Meta Structure Audit

Use this skill when the optimizer must judge Meta settings, not just outcomes.

## Required checks

- objective fit
- CBO vs ABO fit
- budget owner correctness
- optimization event sufficiency
- bid strategy calibration
- learning protection
- cooldown protection

## Output rule

- One primary structural cause.
- One structural action.
- If settings are acceptable, say `No structural change needed`.
