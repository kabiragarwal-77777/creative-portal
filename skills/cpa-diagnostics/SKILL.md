# CPA Diagnostics

Use this skill for:
- high CPA / CAC / signup cost
- rising D0 trial cost
- cost deterioration without obvious spend spikes
- "why is performance weak" and "what should I change today"

## Rules

- Start with benchmark gap, not opinion.
- Check raw-first metrics at account, campaign, adset/ad group, then ad level.
- Split diagnosis into:
  - traffic cost pressure
  - pre-click weakness
  - post-click weakness
  - attribution/tracking uncertainty
  - structural waste
- Do not recommend broad cuts until the main pressure source is identified.
