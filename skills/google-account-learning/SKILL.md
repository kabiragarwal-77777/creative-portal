# Google Account Learning

## Purpose

This skill prevents the Google optimizer from recommending too many meaningful changes at once.

Core rule:
- Do not destabilize a healthy or learning-sensitive Google account through clustered edits.

## Guardrails

- Avoid stacking bid strategy changes, budget changes, keyword changes, and asset refreshes in the same entity at the same time.
- If volume is already unstable, prefer one clear structural fix before broad cleanup.
- Protect efficient campaigns/ad groups from over-editing.
- If one clear loser exists, trim it first before rewriting the whole structure.
- Do not force multiple simultaneous changes across the same budget owner unless the evidence is overwhelming.
- Convert weaker follow-up edits into queue/monitor guidance.

## Output behavior

The optimizer should favor:
- fewer, higher-confidence Google actions
- less bid-strategy churn
- less bulk asset swapping
- less same-day structural overreaction
