# Replacement Intelligence

Use this skill when an ad is fatigued or failing and a replacement decision is required.

## Required order

1. sibling winner in same adset
2. winning pattern in same campaign
3. winning account pattern
4. new brief only if no proven replacement exists

## Output rule

- Name the replacement if one exists.
- If none exists, say what type of creative must be briefed next.
