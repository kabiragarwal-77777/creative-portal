# Performance Benchmarking

Use this skill for:
- weighted median decisioning
- scale / maintain / reduce / pause classifications
- daily analysis
- account reviews

## Rules

- Use weighted medians as the default benchmark anchor.
- Keep benchmark populations maturity-aware and quality-filtered.
- Compare each entity against the correct account benchmark set for its platform and date range.
- Use benchmark deltas in operator explanations.
