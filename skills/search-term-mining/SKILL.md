# Search Term Mining

Use this skill for:
- Google Search deep dives
- wasted spend by query
- negatives opportunities
- high-intent expansion

## Rules

- Separate wasteful terms, weak-intent terms, and winning intent clusters.
- Recommend negatives only when the query pattern is consistently low quality.
- Connect query findings back to CPA, ROAS, and conversion quality.
