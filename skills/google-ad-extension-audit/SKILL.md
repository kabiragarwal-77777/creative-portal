# Google Ad Extension Audit

Use this skill for:
- Search account audit
- CTR weakness
- quality score support analysis

## Rules

- Treat weak extension coverage as a fixable support issue, not the sole root cause.
- Recommend extension improvements when they plausibly improve CTR or relevance.
