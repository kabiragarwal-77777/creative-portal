# Delivery Attribution Reasoner

Use this skill whenever spend-only rows, attribution inflation, or delivery anomalies are present.

## Required diagnosis buckets

- tracking / attribution gap
- delivery throttling
- audience saturation
- post-click failure
- genuine underperformance

## Output rule

- Never auto-pause material spend-only entities.
- State what must be verified first.
