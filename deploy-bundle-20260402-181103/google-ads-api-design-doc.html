Company: Univest Communication Technologies Private Limited

Application: Creative Performance Analytics Portal

Date: March 25, 2026

Version: 1.0

1. Tool Overview

The Creative Performance Analytics Portal is an internal tool built by Univest to monitor and optimize Google Ads campaign performance. It is used exclusively by Univest's in-house performance marketing team to analyze creative assets, track conversion funnels, and make data-driven budget allocation decisions.

The tool is a web-based dashboard (Node.js + Express) that runs on internal infrastructure and is not publicly accessible. It serves approximately 5-10 internal users (marketing team members).

2. Purpose of Google Ads API Usage

The tool uses the Google Ads API exclusively for read-only access to Univest's own Google Ads account data. Specifically:

  • Campaign & Ad Group Performance: Daily spend, impressions, clicks, conversions, and conversion value at the campaign and ad group level.
  • Campaign Metadata: Campaign names, statuses, channel types, and bidding strategies for display in the dashboard.

No write operations are performed. The tool does not modify campaigns, budgets, bids, ads, or any account settings via the API.

4. GAQL Queries Used

Query 1: Campaign + Ad Group Daily Performance

SELECT
    segments.date,
    campaign.id, campaign.name, campaign.status,
    campaign.advertising_channel_type,
    ad_group.id, ad_group.name,
    metrics.cost_micros, metrics.impressions,
    metrics.clicks, metrics.conversions,
    metrics.all_conversions_value
FROM ad_group
WHERE segments.date BETWEEN '{dateFrom}' AND '{dateTo}'
    AND campaign.status = 'ENABLED'
ORDER BY segments.date DESC

Query 2: Campaign List

SELECT
    campaign.id, campaign.name, campaign.status,
    campaign.advertising_channel_type,
    campaign.bidding_strategy_type,
    campaign_budget.amount_micros
FROM campaign
WHERE campaign.status != 'REMOVED'
ORDER BY campaign.name

5. Data Handling & Storage

  • API responses are cached locally for 24 hours to minimize API calls.
  • Data is stored in local JSON cache files and an SQLite database on the server.
  • No Google Ads data is shared externally or with third parties.
  • No personally identifiable information (PII) is accessed or stored.

6. Rate Limiting & Compliance

  • The tool queries the API at most every 6 hours via automated scheduler, plus occasional on-demand refreshes.
  • Estimated daily API calls: 4-10 requests per day.
  • The tool accesses only Univest's own Google Ads account (Customer ID: 324-865-9401).
  • No third-party accounts are accessed.
  • OAuth 2.0 is used for authentication with offline refresh tokens.
